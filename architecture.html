美股晨析 stock-advisor · v3.7 Architecture

Node/Express PWA · S&P500 daily rotation · AI two-round gate · v3.7 action/direction/risk/accuracy/gate layers · port 8090

Visualize format · 今日行动中心

  • 一张卡三行: 新增买入 / 持仓复核 / 卖出复核
  • AI 未运行: 明确不新增仓, 不等于没有机会
  • 市场方向只作背景, 不改写买入门槛
  • 每行展示原因与来源; 锁仓期满也只复核

Visualize format · 方向卡

  • 标题: 市场方向 · 顺风/常态/逆风 (分数)
  • 正文: 一句仓位纪律 (standard/defensive)
  • 5 信号列表: 趋势/宽度/动量/VIX/回撤 + 好中差
  • 缺失态: 数据不足, 按常态纪律办事

Visualize format · 买卖提示卡

  • 买入: 只来自三档门槛 (buy + pass + 低位 + 3/4 质量)
  • 持有/复核/重点复核: 按浮动 -10%/-20% 分级
  • 分级只定复核优先级, 不自动卖出
  • 每卡附: 现价/成本/浮动/解锁倒计时

Visualize format · 验证条

  • 买入组跑赢率 vs 观察组跑赢率 (561 样本)
  • 平均超额 + 样本量, 好坏都展示
  • 阈值冻结声明 + 前向追踪中
  • 全站页脚: 不构成投资建议

Data flow · 单向流动

  • Yahoo/SEC -> pipeline -> data/*.json -> /api/actions -> PWA
  • AI 只写 analyses, 门槛纯代码执行
  • 派生数据 gitignore, 历史 fail-closed
  • AI 故障: Static 降级, 不推送结论

Honesty gates · 诚实闸

  • 无选股分数, 无跑赢宣称 (42.4% buy/27.5% watch)
  • 方向是现状刻画, 不是涨跌预测
  • 阈值冻结, 调参必须升版本
  • 三处同步: 代码 + RUBRIC + 方法页
